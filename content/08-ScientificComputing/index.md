# Scientific Computing

Numerical methods + matrix computations.

## Topics

- **Error analysis** — absolute / relative error, floating-point, conditioning
- **Linear systems** — Gaussian elimination, LU decomposition, pivoting
- **Iterative solvers** — Jacobi, Gauss-Seidel, SOR
- **Interpolation** — Lagrange, Newton, splines
- **Root finding** — bisection, Newton-Raphson, secant
- **Numerical integration** — trapezoidal, Simpson's rule
- **ODEs** — Euler, Runge-Kutta
- **Eigenvalues** — power iteration, QR
