## Data Science topics

- What is data
  - Observation (row), variable (column), cells (values)
  - Tabular data on disk (CSV), in Python (DataFrame, pandas)
- Summarizing a quantitative variable
  - Center: mean, median
  - Spread: variance, standard deviation
- Visualizing one quantitative variable, plotting
- Distributions
  - Joint distribution
  - Conditional distributions
  - Comparing distributions
- Relationships between quantitative variables (correlation coefficient r)
- Multivariate data
- Grammar of graphics (data, aesthetic mappings, geometric objects, facets / labels / scales / themes)
- Distances between observations
  - Distance formula (Pythagorean theorem)
  - Higher dimensions
- Scaling (standardization), z-score, formula
- Calculating distances in scikit-learn
- Encoding categorical variables as quantitative (dummy / one-hot encoding, ColumnTransformer)
- The split-apply-combine paradigm
  - Selecting columns, proportions
- Textual data
  - Document, corpus
  - Text normalization
  - Bag-of-words model
  - N-grams (unigrams, bigrams, ngram_range)
  - Vector space model
  - tf-idf (tf, idf, multiply tf × idf)
