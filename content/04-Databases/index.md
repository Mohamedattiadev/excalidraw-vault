# Databases

Relational database concepts, SQL, and design.

## Topics

- **Relational model** — tables, keys, constraints
- **SQL** — DDL, DML, joins, subqueries, aggregation, window functions
- **Normalization** — 1NF → BCNF, functional dependencies
- **ER modeling** — entities, relationships, cardinality
- **Transactions** — ACID, isolation levels, locking
- **Indexing** — B-trees, hash indexes, query optimization
- **Storage** — pages, buffers, file organization
