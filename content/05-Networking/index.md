# Networking

Computer networks — protocols, architecture, addressing.

## Topics

- **OSI & TCP/IP models** — layer responsibilities, encapsulation
- **Physical & data link** — framing, MAC, Ethernet, ARP
- **Network layer** — IPv4/IPv6, subnetting, routing (RIP, OSPF, BGP)
- **Transport layer** — TCP handshake, congestion control, UDP
- **Application layer** — HTTP, DNS, SMTP, FTP, DHCP
- **Sockets** — client/server programming basics
- **Network security** — TLS, VPNs, firewalls
