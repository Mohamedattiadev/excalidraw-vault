# Algorithms

Visual notes on algorithm analysis & classic problems.

## Topics

- **Asymptotic notation** — O / Θ / Ω, growth rates
- **Sorting** — merge sort, quick sort, radix sort, heap sort
- **Dynamic programming** — 0/1 knapsack, fractional knapsack, coin change
- **Divide & conquer** — matrix multiplication (Strassen), closest pair
- **Greedy** — activity selection, Huffman coding
- **Graph algorithms** — BFS, DFS, Dijkstra, MST
- **Recurrences** — master theorem, substitution
