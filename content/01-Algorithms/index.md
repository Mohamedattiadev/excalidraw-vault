Notes on the algorithms covered in class.

## Topics

- Big O notation
- Recursion
- Sorting
  - Merge sort
  - Quick sort
  - Radix sort
  - Count sort
- Heap and priority queue
  - Binary trees, depth, height
  - Min heap, max heap
  - Build heap, heapify
  - Heapsort algorithm
  - Insert, extract max
- Huffman coding
  - Encoding
  - Constructing a Huffman code
  - Minimize total bits
- Dynamic programming
  - 0/1 knapsack (memoization top-down, bottom-up)
  - Fractional knapsack
- Matrix multiplication (Strassen)
- Graph basics
- BFS (shortest path), DFS
- Shortest path: Dijkstra, Bellman-Ford, Floyd-Warshall
- Minimum spanning tree: Prim, Kruskal
