# Security

Information security fundamentals, crypto, and attacks.

## Topics

- **CIA triad** — Confidentiality, Integrity, Availability
- **Cryptography** — symmetric (AES, DES), asymmetric (RSA, ECC), hashing (SHA), HMAC
- **Key exchange** — Diffie-Hellman, public-key infrastructure
- **Authentication** — passwords, MFA, OAuth, JWT
- **Network attacks** — MITM, replay, DoS/DDoS, ARP spoofing
- **Web attacks (OWASP Top 10)** — XSS, CSRF, SQL injection, broken auth, IDOR
- **Defenses** — firewalls, IDS/IPS, TLS, secure coding
- **Risk & policy** — threat modeling, access control (RBAC, ABAC)
