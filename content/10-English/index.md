Exam-prep revision notes.

## Prerequisites

- Intermediate English (~B1 CEFR) — basic vocabulary + present/past tenses
- A target exam to anchor practice (IELTS, TOEFL, YDS / YÖKDİL, Cambridge B2/C1)
- A bilingual dictionary and a monolingual learner's dictionary (e.g. Oxford Learner's)

## Learning path

1. **Grammar review** — fix the recurring weak spots (tenses, articles, prepositions)
2. **Vocabulary** — build via Academic Word List + topic-based lists, with spaced repetition
3. **Reading** — strategies + question types, read a little every day
4. **Writing** — paragraph structure first, then essay forms
5. **Listening** — accents + note-taking
6. **Speaking** — fluency drills, common prompts, recording yourself

## Topics

- **Grammar review** — tenses (12 forms), conditionals (0–3 + mixed), modals, articles, passive voice, reported speech, relative clauses, gerund vs infinitive, prepositions, subject-verb agreement
- **Vocabulary** — Academic Word List (AWL), topic groups (education, environment, technology, health), collocations, phrasal verbs, idioms
- **Reading comprehension** — skimming, scanning, inferring, question types (MCQ, T/F/NG, matching headings)
- **Writing** — paragraph structure (topic sentence → support → conclusion), essay forms (opinion, compare-contrast, problem-solution, cause-effect), cohesion + linking words, formal vs informal register
- **Listening** — note-taking, gist vs detail, accents (US / UK / AUS), common distractor patterns
- **Speaking** — common topic prompts, fluency vs accuracy, pronunciation (stress, intonation), fillers to avoid
- **Exam tactics** — time management, predicting answers, eliminating distractors, paragraph signposting

**Tenses — quick map**

| Time   | Simple              | Continuous              | Perfect                       | Perfect continuous              |
| ------ | ------------------- | ----------------------- | ----------------------------- | ------------------------------- |
| Present| I work              | I am working            | I have worked                 | I have been working             |
| Past   | I worked            | I was working           | I had worked                  | I had been working              |
| Future | I will work         | I will be working       | I will have worked            | I will have been working        |

**Conditionals**

| Type | Pattern                                              | Use                       |
| ---- | ---------------------------------------------------- | ------------------------- |
| 0    | If + present, present                                | universal truths          |
| 1    | If + present, will + base                            | real future                |
| 2    | If + past, would + base                              | unreal present / hypothetical |
| 3    | If + past perfect, would have + V3                   | unreal past / regret       |
| Mix  | If + past perfect, would + base                      | past cause, present result |

**Essay structure (5-paragraph)**

1. Introduction — hook → background → thesis
2. Body 1 — first reason + example
3. Body 2 — second reason + example
4. Body 3 — counter-argument / third reason
5. Conclusion — restate thesis + final thought

**Common linkers**

- Addition: moreover, furthermore, in addition
- Contrast: however, nevertheless, on the other hand
- Cause: because, since, due to
- Effect: therefore, thus, consequently
- Example: for instance, such as, namely
